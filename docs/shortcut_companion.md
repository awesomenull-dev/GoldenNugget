# GoldenNugget Shortcut Companion («Команды»-компаньон)

Защита от стирания ярлыков на Home Screen при применении твиков.

Проблема: спейс-рестор (фаза 2) стирает иконки на домашнем экране.
Фаза 3 (protective restore) не может вернуть их — это ограничение Apple:
раскладка SpringBoard и ярлыки Home Screen не входят в защитный бэкап.
Поэтому «ярлыки, сделанные через Команды», возвращаются вручную через
шорткат-компаньон: вы сохраняете их в файл до применения, а после
применения повторным запуском возвращаете.

## Ограничение Apple (важно)

iOS **не позволяет** шорткату перечислять/экспортировать всю библиотеку
«Команд» автоматически (нет действия «выгрузить все ярлыки»). Рабочий
обход: вы делитесь нужными ярлыками **в сам компаньон** (шеринг-шит,
можно выбрать сразу несколько), а он складывает их в один архив.

Обычный поток:
1. **Перед применением твиков** — запустить «Nugget Сохранить» и отправить
   в него свои ярлыки (шеринг → «Поделиться содержанием») → получится один
   файл `Nugget-Backup-<дата>.zip` в Files.
2. **После применения** — запустить «Nugget Вернуть»: он откроет этот архив,
   покажет каждый ярлык в режиме предпросмотра → «Добавить команду».
3. Иконки на Home Screen добавить заново в приложении «Команды»
   (кнопка ⋯ → «Добавить на экран „Домой"»). Автоматически их вернуть
   нельзя — то самое ограничение Apple.

## Шорткат 1 — «Nugget Сохранить» (бэкап)

Получает `.shortcut`-файлы через шеринг и упаковывает их в один zip.

Действия по порядку (создаются в приложении «Команды»):

1. **Название**: `Nugget Сохранить`
2. «Получить имя» (Get Name) — [вкл. «Группировать результаты»]
3. «Создать архив» (Make Archive) — формат **zip**
4. «Текущая дата» (Current Date) → «Отформатировать дату» (format: `yyyy-MM-dd HH-mm`)
5. «Переименовать файл» (Rename File) — имя: `Nugget-Backup «дата».zip`
   (альтернатива: пропустить шаги 2/4/5 — сохранить архив как есть)
6. «Сохранить файл» (Save File)
   - *Спросить, куда сохранить* — включено
   - Пользователь указывает папку, например `Мои файлы → GoldenNugget`

Использование: в приложении «Команды» нажать ⋯ на ярлыке →
«Поделиться содержанием» → выбрать **несколько** ярлыков → внизу выбрать
`Nugget Сохранить` (он принимает входящее содержимое).

## Шорткат 2 — «Nugget Вернуть» (восстановление)

Читает папку с бэкапом, распаковывает и показывает ярлыки для добавления.

Действия по порядку:

1. **Название**: `Nugget Вернуть`
2. «Получить содержание папки» (Get Contents of Folder) — выбрать папку
   `GoldenNugget` (туда, куда сохраняли)
3. «Регулярные выражения» не нужны; оставить как есть
4. «Извлечь архив» (Extract Archive / Unarchive) — из `.zip` получаются
   `.shortcut`-файлы
5. «Показать» (Quick Look) — по одному каждому файлу
   На предпросмотре iOS предложит **«Добавить команду»**
6. (Опционально) «Выбрать из списка» (Choose from List) перед шагом 5,
   чтобы не листать все подряд

Использование: запустить `Nugget Вернуть`, листать ярлыки и добавлять их;
затем в «Командах» вернуть иконки: ⋯ → «Добавить на экран „Домой"».

## Как сделать iCloud-ссылку (для QR-кода)

1. В «Командах» открыть `Nugget Сохранить` → ⋯ (⋯) → **«Поделиться командой»**
   → **«Ссылка iCloud»** (iCloud link) → скопировать.
2. Эту ссылку закодировать в QR (статичная картинка со ссылкой на icloud.com).
3. Позже картинка вставляется в попап GoldenNugget перед применением твиков
   (iOS 27): «Добавили ярлыки на главный экран? Сначала сохраните их.
   [QR → Nugget Сохранить]. После применения — повторно запустите восстановление».

## Чек-лист проверки

- [ ] `Nugget Сохранить` в шеринге принимает несколько ярлыков и выдаёт один `.zip`
- [ ] `Nugget Вернуть` распаковывает и показывает «Добавить команду»
- [ ] После добавления иконка появляется на Home Screen
- [ ] Тест: применить твики (фаза 2) → запустить `Nugget Вернуть` → всё на месте
